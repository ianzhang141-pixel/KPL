# 使用说明（零基础分步操作）

> 这份文档假设你**完全没有编程基础**。
> 每一步都会说清楚：在哪里操作、按什么键、看到什么算成功。

---

## 你需要准备的

只有一样：**一场王者荣耀比赛的录像**，或者能在网上播放的比赛回放。

不需要装 ffmpeg，不需要装 Python 包，不需要 API Key。
（后面如果想让机器自动读数字，才需要装东西。第一遍先不用管。）

---

## 第一步：打开终端

「终端」是 Mac 自带的一个程序，长得像一个白底或黑底的方框。

1. 按住键盘上的 `Command` 键，再按一下空格键
2. 屏幕中间会出现一个搜索框
3. 输入 `终端` 两个字（或者英文 `Terminal`）
4. 按回车

一个窗口会打开，里面有一些文字和一个闪烁的光标。就是它了。

---

## 第二步：进入这个项目的文件夹

在终端里输入下面这行，然后按回车。
把 `~/KPL` 换成你实际放这个项目的位置：

```
cd ~/KPL
```

**怎么算成功：** 没有任何红色的错误文字出现，光标前面的路径变了。

如果出现 `No such file or directory`，说明路径不对。
最简单的办法：在终端里输入 `cd ` （注意 cd 后面有一个空格，别按回车），
然后把项目文件夹从访达里**直接拖进终端窗口**，路径会自动填上，再按回车。

---

## 第三步：启动控制台（以后只需要双击）

第一次由 AI 把项目准备好后，在访达中打开项目文件夹，找到：

`启动王者实验室.command`

双击它。系统会自动打开终端并在浏览器中打开控制台。运行期间不要关闭终端窗口。

如果 macOS 第一次阻止打开：按住 Control 点击这个文件，选择「打开」，再确认一次。

下面是备用启动方法，只有双击文件打不开时才需要使用：

输入这行，按回车：

```
python3 -m kplab serve
```

**怎么算成功：** 终端里出现一个方框，里面写着

```
王者荣耀决策实验室：http://127.0.0.1:8020
```

**这个终端窗口不要关，也不要按其他键。** 它关了网页就打不开了。
下面的操作全部在浏览器里做。

如果它提示 `Address already in use`（端口被占用），
说明已经开着一个了，直接跳到第四步。

---

## 第四步：在浏览器里打开控制台

打开 Chrome 或 Safari，在地址栏输入：

```
127.0.0.1:8020
```

按回车。应该看到一个深色的页面，标题是「王者荣耀决策实验室 · 数据控制台」。

页面会显示 ffmpeg、yt-dlp 和自动识别状态。只做人工标注时可以暂时不管。

标定页需先选画面类型：赛事转播固定记分板，或职业/顶尖选手单人视角。
单人视角没有常驻双方总经济是正常现象；系统会把这两项保留为 unknown，
但仍允许识别比赛时间、己方/敌方击杀和小地图，不会用 0 或估算值冒充真实经济。
直接分析网络录像需要 ffmpeg，解析 B站、虎牙、斗鱼网页还需要 yt-dlp。

页面下方的「S44赛季规则库」已经收录用户提供并明确标注为官方说明的当前赛季
刷新时间、兵线、防御塔、原初法阵、视野之灵和野怪规则。绿色条目可参与自动
检查，并优先于非官方实测和个人总结；标为“官方原文存在歧义”或“数值不完整”
的条目只作记录，不会被系统猜成一个数字。

其后的「S44经济机制参考库」来自用户提供的业余实测资料。页面会明确显示哪些
完整公式只能用于低置信度估算、哪些内容仅作参考，以及哪些内容与现有S44规则
冲突。所有经济参考都禁止作为硬性校验或训练真值，4条冲突内容已按官方说明停用。

「S44王者荣耀通识参考库」来自个人总结。刷野、反野、红开、蓝开、切C、换线等
名称可帮助统一人工标注；四一分带、一三一和角色职责只作为解释。页面会特别提示
“中路必须是法师”等过度绝对的说法已经降级。英雄热度榜、装备和召唤师技能属于
版本快照，不能用来自动判定英雄分路，也不会进入训练数据。

---

## 第五步：给这一批录像设置标签

在页面上找到「3 设置这一批录像的样本标签」。

1. 选择样本类型：职业正式比赛、职业选手单排、其他顶尖选手、训练赛或其他。
2. 单人录像填写重点选手；职业比赛填写赛事和重点战队。
3. 游戏版本默认是 S44；导入旧赛季录像时必须改成对应赛季，避免混用数值。
4. 初始权重可以保持默认。它只是为以后训练预留，现在不会启动模型。

职业正式比赛始终保留独立标签，以后既能提高这类样本的权重，也能只筛选它们
分析具体战队的打法；职业选手排位不会冒充战队协同样本。

---

## 第六步：直接添加网络录像来源

在「4 添加网络录像来源」中操作：

1. 把 B站、虎牙、斗鱼的录像网页地址粘贴进去，每行一个；也可以粘贴直接 MP4 或 m3u8 地址。
2. 多网址可以保存为 TXT 后导入；CSV 可以同时填写 `source_url,team,opponent,date,event,note`。
3. 需要登录才能看的录像，选择你已经登录该平台的浏览器。系统直接读取浏览器登录状态，
   不要求你复制 Cookie，也不会把 Cookie 写入日志或 Git。
4. 点击「分析网址」，检查标题、时长、分P、失败和重复状态。
5. 默认勾选可处理且未重复的项目，点击「创建批次并开始流式分析」。

任务开始时系统会根据原始网页地址重新获取有效媒体流，然后让 ffmpeg 连续读取，
边读取边产生稀疏证据帧。媒体地址过期或网络中断时最多重新解析3次；一项失败后，
同批次后面的录像继续处理。

系统不会先下载完整 MP4，也不会永久保存带签名的媒体地址。长期保存的是原始网页地址、
任务状态、结构化结果和少量核对图片。临时缓存上限2GB，超过24小时自动清理；正常流式
路径通常不会产生缓存文件。系统不会绕过登录权限、付费限制或 DRM。

如果页面提示 yt-dlp 未安装，在终端执行：

```
brew install yt-dlp
```

当前电脑已经完成安装，不需要重复执行。

## 第七步：批量拖入本地录像，本机智能提取图片

在控制台的「5 批量选择本地录像并智能抽帧」区域：

1. 保持「智能战术采样（推荐）」不变。
2. 把一段或多段 MP4、MOV、M4V 录像一起拖进蓝色虚线框；也可以点击后多选。
3. 确认列表里的录像数量，点击「批量建档并智能抽帧」。
4. 系统会逐段处理，完成后每段都会显示系统编号和保存了多少张图。

这一步**不会把整段录像上传到服务器、GitHub或第三方云端**。浏览器直接用这台
Mac 解码，只把压缩图片保存进项目。智能模式的基础间隔是：0~4分钟最多8秒、
4~10分钟最多5秒、10分钟以后最多3秒；系统还会每2秒做一次低清变化扫描，
发现画面变化明显时保存该帧。
这比固定30秒可靠得多，同时仍远小于保存整段高清录像。

必须说明：画面变化检测只能判断像素变化，不能假装已经理解了“埋伏、卡线或反野”。
真正识别这些行为还需要后续的小地图位置识别与行为模型。当前方案先保证关键过程不会因为
30秒空档而整段消失。

### 录像放在云端时怎么做

可以把原录像放进 iCloud Drive、Dropbox 或 OneDrive 的同步文件夹，并开启云盘的
「优化存储空间/仅在线」功能。在拖拽框中点击选择文件，从对应云盘文件夹选录像即可。
macOS 会在需要时读取云端文件，分析仍在本机完成，不需要 API Key。

必须说明：电脑要分析画面，就必须至少把正在读取的那部分视频数据传到电脑；不存在
「电脑完全不读取录像却在本地分析」的办法。本系统避免的是**永久复制第二份完整录像**，
并且最终只保留少量帧图。抽帧完成后，原录像可以继续交给云盘自动释放本地空间。

如果浏览器不能播放录像格式，展开页面下方的「兼容模式」，填入录像完整路径，系统会用
ffmpeg直接读取原文件，同样不会复制整段录像。

## 第八步：开始标注（这是最重要的一步）

点页面顶部的「标注页」链接。

### 怎么操作

1. **另开一个窗口播放你的比赛录像**，和标注页并排放着
2. 把录像暂停在某个时刻，比如 2 分 00 秒
3. 在标注页的「这一帧的比赛时间」里填 `02:00`
4. 照着录像画面，把看得清的数字填进去：
   - 记分板上双方的总经济
   - 双方的击杀数
   - 如果看得清，填几个人的等级
5. 如果这段时间里有人拿了暴君或推了塔，在「事件」那里加一条
6. 点「保存这一帧」

然后处理下一张系统抽出的帧，重复上面的步骤。

### 「位置」那一栏怎么填

**不用打字。** 步骤是：

1. 在选手表格里**点一下某个人所在的行**（左边会变蓝，表示选中了他）
2. 到下面那张**小地图示意图**上，点他现在所在的位置
3. 点完会自动跳到下一个人，接着点就行

点完那一栏会显示成人话，比如「蓝方半区 · 上半区（对抗路侧）」或者
「中路 / 河道一带」—— 这是给你核对用的：**如果显示的位置和你看到的对不上，
说明点偏了，再点一次覆盖掉就行。**

那张示意图上：左下角是蓝方基地、右上角是红方，三条路连接两边，
中间那条斜带是河道，上面标了主宰和暴君的大概位置。
**它是示意图，不是等比复刻的地图**，点个大概位置就够了。

如果你已经抽过帧、并且在标定页框过小地图，也可以直接在上方的比赛画面里
点小地图上的英雄，效果一样。

**位置不是必填的。** 看不清谁在哪就跳过，留空会被记成「不知道」。
只有位置信息才能回答「敌方半区出现了几个人」这类问题，
但少填几个人不影响其他数据。

### 三条要记住的规矩

**① 看不清就留空，千万不要猜。**

留空会被记成「不知道」，这是正确的。
瞎填一个数才是灾难 —— 人工填的数字带着最高的可信度进入后面所有环节，
错了以后没有任何一步能发现它。

**② 暴君和主宰是两个不同的东西，别混。**

暴君在下路河道，主宰在上路河道。
暗影暴君是暴君的强化版，风暴龙王是后期独立资源。
这四个在系统里是**四个独立的计数器**，填错了数据就坏了。

（LOL 那个项目就吃过这个亏：先锋和幼虫被算成了大龙，
界面上显示「大龙 6 条」，用那份数据训出来的模型是坏的。）

**③ 先标 10~15 帧就够了，不用标完整场。**

第一遍的目的是**把流程走通、看看这活儿有多累**，不是产出完整数据。

## 第九步：看看数据对不对

回到终端。**不要关掉正在跑控制台的那个窗口** ——
按 `Command + T` 开一个新标签页，然后：

```
cd ~/KPL
python3 -m kplab check KPL2026_AG_vs_EST_G1
```

（把编号换成你自己填的那个）

会打印一份中文报告，告诉你：
标了多少帧、字段覆盖率多少、有没有不可能出现的值、有没有读数被拒绝。

**报告里出现「❌ 不通过」不代表你做错了。**
第一次标 10 帧，覆盖率肯定不高，这是正常的。
重点看有没有「违反游戏规则的值」那一段 —— 那才是真的填错了。

---

## 第十步：逐帧核对

回到浏览器，点顶部的「逐帧核对页」。

上面会显示每一帧的完整局势。注意三种颜色：

- **白色**：可信的值
- **黄色带问号**：可信度不够，只能参考
- **灰色的横线**：不知道

第一遍全部人工标注的话，应该都是白色的（因为人工填的可信度最高）。

## 常见问题

**问：终端里出现一大堆红色文字怎么办？**
把那些文字**整段复制**下来贴给 AI。不要只说「报错了」，
红色文字里通常已经写清楚了原因。

**问：控制台页面打不开？**
检查跑 `serve` 的那个终端窗口还在不在、有没有被关掉。

**问：一定要装 ffmpeg 吗？**
不用。装了它可以自动把录像切成图片，标注时不用手动拖进度条，方便一些。
但不装完全不影响标注。

**问：什么时候能看到胜率曲线？**
现在还没有。整个仓库里没有任何模型 —— 这是有意的。
在数据被核对清楚之前做出来的曲线是假的，那正是这个项目想避免的事。
